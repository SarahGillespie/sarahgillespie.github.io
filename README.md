# Sarah Elizabeth Gillespie's personal homepage

[Homepage Link](https://sarahgillespie.github.io/)

## Project Objective

This homepage is a website designed by Sarah Gillespie for the purpose of displaying her relevant work, academics, projects, and birdwatching hobby.

## Installation

See the included package.json file listing all the specific dependencies of the project.

### Installation Steps and

1. Clone or download this repository to your local machine

2. Navigate to the project directory:

```bash
   cd project-1/draft
```

3. Install dependencies:

```bash
   npm install
```

4. (Optional) Run Prettier to format code:

```bash
   npm run format
```

5. (Optional) Run ESLint to check for errors:

```bash
   npm run lint
```

### Instructions to build

Use Python's HTTP Server

```bash
   python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser
